# Save States
This folder contain states for each part of the game (these are Bizhawk states)
- [P01]_start.State : just after the intro cutscene
- [P02]_start.State : right when you enter the Cave of Nagi with Kuni for the first time
- [P03]_start.State : right when you enter Shinsu field after cutting the giant boulder in Kamiki
- [P03]MasterAnura.State : right before falling in the hole which lead to the boss fight
- [P04]_start.State : right when you enter Shinsu field after blooming Sakuya's tree
